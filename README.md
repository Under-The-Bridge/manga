# WebManga

Laravel 12 + Blade. Десктопные страницы по макету Figma: главная, вход, регистрация, страница тайтла. Ширина контента — 1120 px; мобильная версия не входит в эту реализацию.

## Запуск

Нужны PHP и расширения, совместимые с `composer.lock`, Composer и SQLite (либо настроенная другая БД).

```sh
composer install
cp .env.example .env
php artisan key:generate
```

Создайте пустой файл `database/database.sqlite`, затем:

```sh
php artisan migrate
php artisan serve
```

CSS, JavaScript, шрифты Inter и изображения находятся в `public/`. Для этих Blade-страниц сборка Vite и `npm install` не требуются. Лицензия Inter — `public/fonts/Inter-LICENSE.txt`.

## Страницы

- `/` — главная, поиск через `?q=`, фильтр через `?genre=`.
- `/login`, `/register` — формы с серверной валидацией, CSRF, ограничением частоты запросов и сессионной авторизацией.
- `/manga/fullmetal-alchemist` — страница из макета без разделов «Связанное» и «Похожее».

Общий каркас — `resources/views/template.blade.php`, шапка и подвал — отдельные шаблоны. Повторяющиеся карточки и строки статистики — `resources/views/partials/`.

Содержимое манги и статистика пока демонстрационные, из макета (`config/webmanga.php` и шаблон тайтла). Другие карточки открывают тот же шаблон с доступными сведениями. Главы, отзывы, обсуждения и оценки ещё не подключены к БД: соответствующие вкладки показывают пустое состояние. «В планах» сохраняется только в браузере на этом устройстве. Восстановление пароля и контакты проекта не настроены; интерфейс сообщает об этом без имитации отправки.
